# LocalTutor Match

## The idea
Help families find tutors by subject, language, availability, and service area. Start with a small number of verified tutors and one locality.

## Users and value
Learners find relevant help; tutors get new clients and manage lesson requests. Revenue can come from a tutor subscription or a fee on confirmed bookings.

## MVP scope
- Tutor profiles with subjects, language, availability, and service format.
- Search and basic filters.
- Lesson request, tutor response, and booking status.
- Learner feedback after a completed lesson.

## Delivery and optional technology
Estimated MVP: **4 to 6 weeks**. Build a responsive app; families can use it without installing anything. Optional stack: Vue or React, Node.js or PHP, and MySQL or MongoDB.

## Keep out of the first release
Set clear expectations about tutor checks and reviews. Do not promise academic outcomes or publish private contact details before a booking is accepted.
