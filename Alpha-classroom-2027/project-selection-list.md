# Alpha Classroom 2027 Capstone Project Selection

This list is a starting point for practical capstones for the Alpha classroom. Each idea targets a real need in an African community and has a plausible paying customer, while keeping the first release small enough for a student or small team. Projects are web and mobile friendly, including responsive web apps and progressive web apps. The estimates are for an MVP, not a production-ready service.

Students should confirm the target community and assumptions with potential users before building. Assignments are currently open. A technology stack is a suggestion, not a requirement; choose the tools that fit the team's skills and the project.

## Delivery guidance

Use the listed estimate as a planning range and cut scope before cutting testing. Interview a few intended users, agree on one pilot location and one primary user journey, then build only what is needed to test that journey. A one-month MVP should favor a responsive web app or progressive web app, manual review where needed, and a small set of clear workflows. Add mobile-specific features, automated integrations, and additional regions only when the pilot proves they are useful.

Use sandbox or mock payment flows for a classroom MVP. Do not hold customer funds or present an unlicensed service as a bank, insurer, clinic, or payment provider. Health projects should protect personal information, use qualified professionals for clinical content, and avoid diagnosing users. Safety and civic projects should minimize personal data, prevent public exposure of sensitive locations, and include moderation.
