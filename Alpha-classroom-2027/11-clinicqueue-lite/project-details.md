# ClinicQueue Lite

## The idea
Help a small clinic manage appointment requests and an on-site queue using a simple phone-friendly interface. It supports clinic operations and does not provide medical advice.

## Users and value
Patients can request a visit slot and check queue progress; clinic staff can reduce paper-based coordination. Revenue could be a clinic subscription sized for a small facility.

## MVP scope
- Clinic profile, services, and staff-managed availability.
- Appointment request and confirmation.
- Queue token and visit status managed by clinic staff.
- Daily clinic view and basic appointment history.

## Delivery and optional technology
Estimated MVP: **5 to 7 weeks**. Use a responsive web app or progressive web app. Optional stack: Vue or React, Node.js or PHP, and MySQL. Keep video calls outside the first release.

## Keep out of the first release
Store as little health information as possible. Validate workflow with clinic staff, control access to patient records, and avoid claims of emergency service.
