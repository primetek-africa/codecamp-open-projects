# CareConnect Telehealth Booking

## The idea
Help people find and book remote consultations with participating, appropriately licensed clinicians. The MVP handles discovery and scheduling; consultations can use an existing provider platform.

## Users and value
Patients find available clinicians; clinicians organize remote appointments. Revenue can come from clinician subscriptions or a disclosed booking fee.

## MVP scope
- Clinician profile with service area, qualifications, and verification state.
- Availability and appointment booking.
- Consultation link or provider-selected contact method.
- Payment status and follow-up note visible only to the clinician and patient.

## Delivery and optional technology
Estimated MVP: **6 to 8 weeks**. Start with a responsive web app and use a third-party meeting service. Optional stack: React or Vue, Node.js or PHP, and MySQL.

## Keep out of the first release
Verify licensing and local telehealth requirements before a pilot. Do not offer automated diagnosis, emergency care, or store unnecessary clinical notes.
